Featured Project

Serverless Computing Framework for Edge Devices

Problem: Most systems send data from edge devices to the cloud for processing. This leads to high latency and increased network usage. Systems often fail when internet connectivity is unstable. Most serverless platforms are too resource-heavy for edge devices with limited memory and processing power.

Solution: A lightweight serverless framework was designed for edge devices. Data is processed locally instead of relying on the cloud. MQTT is used for fast event communication. Python functions handle data processing at the edge. Docker ensures consistent and portable execution. SQLite stores data locally for quick access.
