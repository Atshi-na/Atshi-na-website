Final Year Project · 2025
Serverless Computing Framework
for Edge Devices
Python Docker MQTT SQLite Edge Computing
The Problem

Most systems send data from edge devices to the cloud for processing — causing high latency, increased network usage, and failure when connectivity is unstable. Existing serverless platforms are too resource-heavy for constrained edge hardware.

The Solution

A lightweight serverless framework designed to process data locally at the edge. MQTT handles fast event communication, Python functions execute data processing tasks, Docker ensures portable execution, and SQLite stores data locally for quick access.

Personal Project · 2026
Netflix Movies & TV Shows
Exploratory Data Analysis
Python Pandas NumPy Matplotlib Google Colab
The Problem

Netflix's public catalog data is messy out of the box — missing directors, cast, and countries, durations blended across minutes and seasons in one column, and a handful of misplaced values sitting in the wrong fields entirely. Raw like this, it can't reliably answer even basic business questions.

The Solution

An end-to-end EDA workflow on 8,800+ titles: cleaning and restructuring the dataset, engineering new features (duration_value, duration_unit, added_year), and exploring content type, genre, country, rating, director, and actor trends with Pandas and Matplotlib to surface Netflix's content strategy and growth patterns from 2008–2021.
